# Petween Desktop 发布 PV 脚本 v1（为 justanothervocal 配曲而写）

> 用途：B站主片（科技→软件应用），零解说、音乐驱动、真机录屏快切。
> 参照系：Cursor 2.0 发布片（64s / 10 场景 / 零解说 / 940 万播放）。
> 本文是**作曲与拍摄的共同底稿**：时间结构以音乐小节为骨架定死，画面与音效挂在上面。

## 0. 音乐简报（先读这个）

| 项 | 定死 | 说明 |
|---|---|---|
| 时长 | **80 秒 = 40 小节** | 允许 ±4s 浮动，锚点见下 |
| 速度 | **120 BPM，4/4** | 1 小节 = 2.0 秒整——剪辑卡点和你的小节线永远对齐 |
| 情绪 | 亮色、俏皮的 electro / electropop | 允许 8-bit 音色点缀（拉窗/便签段落）；整体是"可爱但靠谱"，不甜腻 |
| 人声 | 可有 | 你的 vocal 作为旋律层完全欢迎；drop 段落建议以乐器为主给人声让位（画面 SFX 密） |
| 必须踩住的 6 个锚点 | 0:06 起拍 / 0:14 蒙太奇 / **0:36 drop** / 0:52 抽空 / 1:10 全片峰值 / 1:16 尾音 | 这些秒数上发生关键画面事件（见分镜），音乐事件要落在上面 |
| 能量曲线 | 静→脉冲→groove→riser→**drop**→breakdown→次高峰→**峰值**→收 | 双峰结构，1:10 的峰值要全片最满 |

如果曲子自然写成了 84s 或段落对不上锚点：没关系，把你的段落小节图给我，我按曲子重排镜头——**锚点的相对顺序不变就行**。

## 2. 逐段分镜

### S0 钩子（0:00-0:06，近静音）

- **0:00** 黑场半秒 → 真实桌面。左边终端里 agent 开始滚动输出（键盘雨声）。右下角宠物在打盹，z-z-z 动画。
- **0:04** 音效①：回车键声。宠物耳朵动了一下，没醒。
- 0:06 前一瞬：一切安静得可疑。
- 音乐：只有极稀的 pad / room tone + 滤波。**第 4 小节的 kick 就是"宠物上岗"的发令枪。**
- 字幕卡：无（保持真实感，此刻不需要解释）。

### S1 起拍（0:06-0:14）

- **0:06.0（锚点）kick 落下 = 宠物弹起、切换思考脸**（音效②：短 pop）。
- 0:06-0:10 镜头推近宠物（录屏放大裁切即可）：思考脸特写，思考泡泡弹出、计时开始走字；背景里终端继续滚。
- 0:10-0:14 拉回全景：宠物 vs 终端同框。
- 字幕卡（0:08，停 2 小节）：**「它在替你盯着 AI」**
- 音乐：主乐器动机第一次出现——**这段动机后面 drop 会复用，建议当成产品的旋律签名来写**。
- 音效：③ 泡泡弹出（soft pop）、④ 计时 tick（每拍一格）。

### S2 状态蒙太奇（0:14-0:30，每 2 小节 = 1 个状态）

| 时间 | 状态画面 | 字幕卡 | 音效 |
|---|---|---|---|
| 0:14 | 思考脸 + 计时泡泡走字 | 「思考中…」 | tick |
| 0:18 | 工作中：编辑行数泡泡数字滚动 | 「写代码中…」 | 键盘雨 + 数字跳 |
| 0:22 | **等授权脸**（宠物盯着你） | 「…又要我确认?!」 | ⑤ 滑音/闷响（喜剧空拍） |
| 0:26 | 成功：庆祝动画 + 一小撮粒子 | 「搞定!」 | ⑥ 上行双音 |

- 0:22 是全片第一个喜剧点，音乐留半拍空或一个故意掉拍的音。
- 0:28-0:30：宠物满足地晃了晃，起身——**衔接 S3**。

### S3 预备（0:30-0:36，riser）

- 0:30 宠物开始在桌面上溜达（游荡动画），越走越靠近屏幕边缘。
- 0:34 走到边缘，**探头窥视**（半个身子探出屏幕外再缩回来）。
- 0:35-0:36 第 18 小节末：画面/音乐双双抽空半拍——一瞬间的安静。
- 字幕卡（0:32）：**「你不在的时候——」**（话说一半，drop 接下半句）
- 音乐：riser / snoll roll / 滤波扫频任选，1:36.0 必须松手。

### S4 DROP（0:36-0:52，全能量）

- **0:36.0（锚点）drop 落下 = 第一张内容窗从屏幕边缘猛滑入**（音效⑦ whoosh+slam，正好盖在 kick 上）。
- 0:36-0:42 连拉 2-3 张内容窗（内容池放你的图），每张踩一个重拍；宠物在窗前得意。
- 0:42-0:46 贴便签 ×3，卡点（音效⑧：拍立得 pop ×3）；便签随机歪斜地钉在屏幕各处。
- 0:46-0:48 冲过屏幕（疾走 whoosh，音效⑨）。
- 0:48-0:52 **投掷物理**：一只手（真实光标）抓起宠物甩出 → 撞屏幕边缘弹跳 ×3（音效⑩ bounce 递进）→ 落定（thud）。
- 字幕卡（0:38，停 2 小节）：**「它也不会闲着」**——和 S3 的半句接成完整台词。
- 音乐：全能量。8-bit 音色点缀拉窗/便签；bounce 三连要能听见音效，别糊。

### S5 桥段（0:52-1:00，breakdown）

- 鼓组抽掉（锚点 0:52）。画面切到**一个完整回合的泡泡生命周期**，四拍四个事件：
  - 0:52 思考计时归零 → 0:54 行数定格 → 0:56 回复摘要泡泡展开 → 0:58 完成提醒弹出（「回合完成」卡）。
- 字幕卡（0:54）：**「AI 干活，你看着」**
- 音乐：只留 bass + 拨奏/arp + vocal（如果你的人声有慢板段，放这里最合适——画面最静，人声最突出）。

### S6 终段（1:00-1:12，双段爬升）

- 0:60-0:66 三连接器快闪，各 2 小节：zcode 终端 → Claude Code 终端 → Codex 终端，宠物状态各自切换。字幕卡依次：**「zcode」「Claude Code」「Codex」**，0:65 合并成一张三联卡。
- 0:66-0:70 编辑器快闪，各 1 小节：时间轴拖动 → bezier 曲线拉弯 → 一键换肤（宠物当场变样）。
- **1:10.0（锚点，全片峰值）= 音乐最满的一拍上，成功回合触发、六种粒子齐爆（heart-burst + firework 齐上），宠物庆祝动画**。
- 字幕卡（1:06）：**「还能做你自己的宠物」**
- 音乐：0:60 起从 breakdown 爬回次高峰，1:10 峰值 hit + 长混响尾。

### S7 尾声（1:12-1:20）

- 0:72 粒子散尽，宠物打了个哈欠，睡去（z-z-z）。画面缓缓压暗。
- 0:76（第 38 小节，尾音落点）**logo 卡**：Petween + 一句话——**「AI 干活，它监工」**。
- 0:76-1:20 CTA 卡（与尾音同现）：「免费 · 开源 · Windows」+ GitHub 地址 + 二维码 +「B站搜 Petween」。
- 0:79-1:20 收黑，最后一个音自然衰减。

## 4. 附录 A：拍摄素材清单（一条一录，后期按小节剪）

## 5. 附录 B：录制环境清单

- OBS 显示器捕获，画布=输出=屏幕原生分辨率，1080p60，NVENC CQP 16-18。
- **保留真实系统光标**（点击穿透的镜头恰恰需要无特效光标才可信）。
- 干净 shell + 假项目沙盒：占位密钥、demo 用户名、无真实路径；关 Windows 通知（toast 会弹进画面）、关其他应用。
- 终端/编辑器字号调大 2-3 档（录屏小字必糊）；桌面壁纸换干净纯色或简洁图。
- 宠物固定放右下（与分镜一致）；深色桌面 + 深色终端的对比已足够，别再叠 HDR。
- 每条素材前后多留 2 秒余量。
